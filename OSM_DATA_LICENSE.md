Source: https://api.openstreetmap.org/api/0.6/map?bbox=19.075,47.495,19.085,47.505

Raw downloaded XML is retained as data/budapest_source.osm. A converted node/way JSON source and derived matrices are distributed alongside the code so the geographic database is available for inspection and reproduction. The included converter ignores relations; it does not model turn restrictions. The JSON source hash is embedded in the road instance. Third-party data licensing does not become the project's code license.

The existing furniture orders are synthetic/catalog-proxy orders and are not customer records. Simulated delivery locations sampled from OSM nodes do not establish real-world service demand or safe unloading access. No identity, home address or live device location was accessed.
