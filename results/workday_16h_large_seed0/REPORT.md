# Budapest shared cases 075-099: seed-0 GA comparison

All 50 final schedules passed revalidation. On the penalty-inclusive
objective, relocate-only recorded **25 wins, 0 ties,
and 0 losses** across 25 pairs. The median paired penalty
reduction (original minus relocate) was **EUR 124,000.00**.

| Arm | Mean operating cost (EUR) | Mean soft penalty (EUR) | Mean total objective (EUR) | Mean recorded runtime (s) | Zero penalty |
|---|---:|---:|---:|---:|---:|
| Original GA | 1,778.96 | 252,240.00 | 254,018.96 | 115.86 | 0/25 (0%) |
| Relocate only | 1,730.96 | 147,600.00 | 149,330.96 | 46.27 | 0/25 (0%) |

Cases have 225-249 addresses. Each pair shared the same verified initial
schedule, seed 0, population 32, a limit of 200 generations, and a cap of
6,032 counted operations. Swap was disabled. One GA candidate evaluation
and one cross-trip trial each debit one unit, with different computational
costs. The per-run CSV gives GA evaluations and local trials separately.

Reused 25 original and 2
relocate-only checkpoints after checking instance and initial-plan hashes,
solver fingerprints, and settings. Runtimes retain the original measurement
conditions for reused checkpoints. The means are descriptive because the
runs were recorded in different batches with parallel workers.

The original per-run JSON records are retained locally and are not included
in this PR. The `reused_from` paths in the summary and `source_checkpoint`
paths in the top-level trace CSV identify original run records; they are
provenance text, not links to records supplied by this PR. A fresh checkout
runs missing pairs instead of reusing those omitted records.

To reproduce from the repository root, use a fresh output directory:

```powershell
python run_workday_large_seed0.py --instances generated/shared_workday_16h_pilot_local --output results/workday_16h_large_seed0_repro --jobs 8
```

Generate the instances first using the commands in the
[benchmark report](../../WORKDAY_16H_BENCHMARK.md#reproduction-commands).
This runner writes its own summary, paired differences, aggregate statistics
and report as part of the solving workflow. The top-level trace CSV and
baseline analysis tables and figure are supplied separately and are not
automatically generated by this command.

To resume a new run, use the same command and output directory with
`--resume`, retaining the checkpoints generated by that run. The original
checkpoints omitted from this PR are not available on a fresh checkout.
